# Security Policy

## Reporting

Report vulnerabilities via GitHub Private Vulnerability Reporting:

https://github.com/yolo-labz/craftcut/security/advisories/new

No PGP keys. No email. Private advisories only.

## Supply chain

Releases carry Sigstore attestations (`gh attestation verify`) and CycloneDX + SPDX SBOMs attached to every GitHub Release. PyPI artifacts carry PEP 740 attestations.
