# `section-map.yaml` Schema

The section map is the narrative blueprint consumed by `craftcut restructure`. It
sits at `<project>/section-map.yaml` and is hand-edited (or generated by Claude
Code during a planning pass).

## Top-level keys

| Key              | Type    | Required | Description                                       |
|------------------|---------|----------|---------------------------------------------------|
| `schema_version` | int     | yes      | Must be `1`.                                      |
| `project`        | string  | yes      | Human-readable label; echoed into OTIO timeline.  |
| `sections`       | list    | yes      | Ordered narrative beats; min 1.                   |

## `sections[]`

| Key         | Type   | Required | Description                                    |
|-------------|--------|----------|------------------------------------------------|
| `name`      | string | yes      | Section slug (e.g. `intro`, `cut`, `finish`).  |
| `segments`  | list   | yes      | Ordered clip slices forming this section.      |

## `segments[]`

| Key     | Type   | Required | Description                                            |
|---------|--------|----------|--------------------------------------------------------|
| `clip`  | string | yes      | Clip stem (NFC-normalized, matches `media/*.mov`).     |
| `start` | float  | yes      | Inclusive start, seconds.                              |
| `end`   | float  | yes      | Exclusive end, seconds. Must be `> start`.             |

## Example

```yaml
schema_version: 1
project: bolsa-de-viagem
sections:
  - name: intro
    segments:
      - { clip: IMG_1001, start: 0.0,  end: 12.0 }
  - name: materials
    segments:
      - { clip: IMG_1002, start: 4.5,  end: 38.2 }
      - { clip: IMG_1003, start: 0.0,  end: 18.7 }
  - name: cut-pattern
    segments:
      - { clip: IMG_1004, start: 0.5,  end: 96.0 }
  - name: outro
    segments:
      - { clip: IMG_1020, start: 0.0,  end: 9.5 }
```

## Invariants enforced at load time

- YAML is parsed with `ruamel.yaml`'s `typ="safe"` — tags / constructors refused.
- `FR-044`: anchors / aliases on non-scalar nodes are rejected with `BadInputError`.
- `FR-046`: the path is resolved via `realpath` and must stay within
  `<project>`; override via `--allow-outside-root` (audit-logged).
- All `clip` stems are NFC-normalized before lookup (matches iOS NFD input).
- `end > start` per segment; `sections` must not be empty.

## Pacing heuristic

`restructure` emits `pacing_warning: true` when cuts-per-minute falls outside
`[4.0, 12.0]`. Silence with `--accept-pacing` if intentional.
